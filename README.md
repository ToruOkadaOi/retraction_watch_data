# Retraction Watch Data

This repository contains the latest mirrored snapshot of [Crossref's Retraction Watch dataset](https://gitlab.com/crossref/retraction-watch-data), generated on **2026-10-30**.

The dataset is accompanied by a knowledge graph and an interactive research dashboard.

[**Research Dashboard**](https://toruokadaoi.github.io/retraction_watch_data/) · [**API Documentation**](https://retraction-watch-data.onrender.com/docs)

## Dataset

The Retraction Watch database documents scientific retractions, corrections, expressions of concern, and other publication updates across disciplines.

Maintained by Retraction Watch and made publicly available by Crossref, the dataset includes publication metadata, authors, institutions, journals, notice dates, and documented reasons for retraction.

## Knowledge Graph

The knowledge graph connects publication records with author names, institutions, and journals, while retaining documented retraction reasons.

**Note:** Author and institution connections are based on exact name matches, not verified identities.

## Notes

- Retractions do not necessarily indicate misconduct.
- Notice counts should not be interpreted as retraction rates.
- The hosted graph and repository dataset may reflect different snapshots.
